# SoyAgeing-R1: MambaVision with Dual Augmentation and Foreground-Background Feature Distillation (DA+FD)

This repository contains the official codebase, evaluation scripts, and training logs for soybean ageing classification using an optimized MambaVision-B architecture.

## Performance Summary
- **Baseline Accuracy**: 79.39%
- **Final Top-1 Accuracy**: **85.05%** (Epoch 200)
- **Final Top-5 Accuracy**: **95.76%**
- **Macro F1-Score**: 84.83%
